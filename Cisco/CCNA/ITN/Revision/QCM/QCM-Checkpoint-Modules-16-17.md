## Réponses et Explications

### Question 1
**Réponses correctes : a, c, e**

**Explication :**
Le triangle CIA est le fondement de la sécurité informatique :
- **Confidentialité (Confidentiality)** : Seules les personnes autorisées accèdent aux données
- **Intégrité (Integrity)** : Les données ne sont pas altérées ou modifiées sans autorisation
- **Disponibilité (Availability)** : Les services et données sont accessibles quand nécessaire

**💡 Point clé :** CIA est l'acronyme universel en sécurité informatique. Tous les contrôles de sécurité visent à protéger un ou plusieurs de ces trois aspects.

---

### Question 2
**Réponses correctes : a, c, d**

**Explication :**
Configuration SSH sur Cisco en 3 étapes obligatoires :

```cisco
! 1. Configurer hostname
hostname R1

! 2. Configurer nom de domaine
ip domain-name company.local

! 3. Générer clé RSA
crypto key generate rsa modulus 2048
```

Ces trois éléments sont nécessaires car la clé RSA utilise le hostname et le domaine (FQDN) dans sa génération.

**💡 Point clé :** Sans hostname et domaine, la commande `crypto key generate rsa` échouera.

---

### Question 3
**Réponse correcte : b**

**Explication :**
`service password-encryption` chiffre automatiquement tous les mots de passe en clair de type 7 :

```cisco
Router(config)# service password-encryption
```

**Affecte :**
- Mot de passe console
- Mot de passe VTY
- `enable password` (pas `enable secret` déjà en MD5)

**💡 Point clé :** Le chiffrement Type 7 est faible mais mieux que rien. `enable secret` (MD5) est toujours préférable pour le mode privilégié.

---

### Question 4
**Réponse correcte : b**

**Explication :**
Un petit réseau nécessite typiquement **2 couches** :
- **Distribution** : Routage inter-VLAN, connexion Internet
- **Accès** : Connexion des périphériques finaux

La couche Core n'est nécessaire que pour les grands réseaux (campus, multi-sites).

**💡 Point clé :** Le routeur ISR intégré combine souvent les fonctions de distribution dans un petit réseau.

---

### Question 5
**Réponse correcte : b**

**Explication :**
**DoS (Denial of Service)** vise à rendre un service indisponible en :
- Saturant la bande passante
- Épuisant les ressources système (CPU, mémoire)
- Provoquant des crashs

**Types courants :**
- SYN Flood
- UDP Flood
- Ping of Death
- Smurf Attack

**💡 Point clé :** DDoS (Distributed DoS) utilise plusieurs sources (botnet) pour amplifier l'attaque.

---

### Question 6
**Réponse correcte : c**

**Explication :**
**Symptômes :**
- `ping 8.8.8.8` : OK → Connectivité IP fonctionne (couches 1-3 OK)
- `ping www.cisco.com` : ÉCHEC → Résolution de nom impossible

**Diagnostic :** Problème DNS

**Dépannage :**
```cmd
ipconfig /all                # Vérifier serveur DNS
nslookup www.cisco.com      # Tester résolution
ipconfig /flushdns          # Vider cache
```

**💡 Point clé :** "Ping IP OK, ping nom KO" = TOUJOURS problème DNS.

### Question 8

AAA signifie :
- **Authentication** : "Qui êtes-vous ?" - Vérification de l'identité
- **Authorization** : "Que pouvez-vous faire ?" - Permissions et privilèges
- **Accounting** : "Qu'avez-vous fait ?" - Journalisation et audit

### Question 9
**Réponse correcte : c**

**Explication :**
**Divide and Conquer** est généralement la plus efficace :

1. Tester couche médiane (3 ou 4)
2. Si OK → Problème couches supérieures
3. Si KO → Problème couches inférieures
4. Diviser à nouveau

**Avantage :** Élimine rapidement 50% des possibilités à chaque test.

**💡 Point clé :** Nécessite de l'expérience mais économise beaucoup de temps.

### Question 10
**Réponse correcte : b**

**Explication :**
`enable secret` utilise MD5 (Type 5), beaucoup plus sécurisé que `enable password` (Type 7).

```cisco
Router(config)# enable secret Str0ng@P@ss!
```

**Comparaison :**
- `enable password` : Type 7 (réversible)
- `enable secret` : MD5 Type 5 (irréversible)

**💡 Point clé :** Si les deux sont configurés, `enable secret` prend la priorité. Toujours utiliser `enable secret`.

### Question 11
**Réponses correctes : a, c, d**

**Explication :**
Un routeur ISR (Integrated Services Router) intègre :
- **Routage** : Fonction principale
- **NAT/PAT** : Traduction d'adresses
- **Serveur DHCP** : Attribution IP automatique
- Pare-feu (ACL)
- VPN
- Switch intégré (optionnel)

**💡 Point clé :** "Integrated Services" = plusieurs services réseau dans un seul équipement.

### Question 12

**💡 Point clé :** Si pare-feu bloque UDP 53, résolution de noms impossible.

### Question 13
**Réponse correcte : b**

**Explication :**
**Duplex mismatch** provoque :
- Connectivité intermittente
- Nombreuses collisions
- Performances dégradées
- Erreurs CRC

**Vérification :**
```cisco
show interfaces <port> | include duplex
```

**💡 Point clé :** Cause TRÈS fréquente de problèmes de performance. Toujours vérifier duplex/speed lors de problèmes intermittents.

### Question 15
**Réponse correcte : b**

**Explication :**
`transport input ssh` restreint l'accès VTY à SSH uniquement :

```cisco
Router(config)# line vty 0 4
Router(config-line)# transport input ssh
Router(config-line)# login local
```

**Options :**
- `transport input ssh` : SSH uniquement ✅
- `transport input telnet` : Telnet uniquement
- `transport input all` : Tous protocoles (défaut)
- `transport input none` : Aucun accès

**💡 Point clé :** TOUJOURS utiliser `transport input ssh` en production pour bloquer Telnet.

### Question 17
**Réponse correcte : b**

**100 mètres** est la longueur maximale pour câble Ethernet UTP entre équipements actifs.

**Au-delà :**
- Atténuation du signal

### Question 30
**Réponses correctes : b, c**

**Explication :**
**DHCP** utilise deux ports UDP :
- **Port 67** : Serveur DHCP
- **Port 68** : Client DHCP

**Échange DHCP :**
1. DHCP Discover (client → broadcast)
2. DHCP Offer (serveur → client)
3. DHCP Request (client → serveur)
4. DHCP Ack (serveur → client)

**💡 Point clé :** Si pare-feu bloque UDP 67-68, DHCP ne fonctionnera pas.
