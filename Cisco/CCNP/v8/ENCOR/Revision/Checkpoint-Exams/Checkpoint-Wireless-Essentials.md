## SECTION 1 : SIGNAUX WIRELESS & INFRASTRUCTURE (Q1-Q20)

**Question 1**: Bande 2.4 GHz Wi-Fi plage exacte :
- A) 2.0 - 2.5 GHz complet utilizable
- B) 2.4 - 2.5 GHz
- C) 2.400 - 2.4835 GHz
- D) 2.412 - 2.484 GHz

**Réponse**: C) 2.400 - 2.4835 GHz ✓

---

**Question 2**: Canaux non-overlappant 2.4 GHz pour déploiement multi-AP :
- A) 1, 2, 3 (contiguës)
- B) 1, 5, 9
- C) 1, 6, 11
- D) Tous les 14 possible sans interférence

**Réponse**: C) 1, 6, 11 ✓

---

**Question 3**: Bande 5 GHz structure :
- A) Une bande continue unique
- B) 4 bandes séparées + 2 brèches non-usables
- C) 10 sous-bandes avec gaps multiples
- D) Continu depuis 5.0 - 6.0 GHz

**Réponse**: B) 4 bandes séparées + 2 brèches non-usables ✓

---

**Question 4**: 5 GHz avantage principale comparé 2.4 GHz :
- A) Plus grand portée per AP
- B) Moins d'interférence, nombreux canals non-overlappant
- C) Meilleur pénétration murs
- D) Moins cher d'équipement

**Réponse**: B) Moins d'interférence, nombreux canals non-overlappant ✓

**Question 7**: Décibel (dB) calcul pour comparer puissances :

**Question 10**: 802.11ac surcharging principale vs 802.11n :

**Question 13**: Split-MAC Architecture dans topologie Lightweight :

## SECTION 2 : ROAMING & SERVICES LOCALISATION (Q21-Q50)

**Question 21**: Client roaming décision basée sur :
- A) WLC force basé sur client utilization
- B) AP active scan clients
- C) Client détecte RSS dégradation, sélectionne meilleur signal
- D) Aléatoire selection

**Réponse**: C) Client détecte RSS dégradation, sélectionne meilleur signal ✓

---

**Question 22**: Durée roaming standard sans optimisation :
- A) < 50 ms
- B) 100-500 ms
- C) 1-2 secondes
- D) 5+ secondes

**Réponse**: C) 1-2 secondes ✓

---

**Question 23**: Roaming entre deux APs même WLC :
- A) Client perd connexion brièvement
- B) WLC met à jour association client, roaming transparent
- C) Tunnel créé temporaire
- D) Client DHCP release obligatoire

**Réponse**: B) WLC met à jour association client, roaming transparent ✓

---

**Question 24**: Client roame WLC1 (VLAN100) → WLC2 (VLAN200) :
- A) Client IP change automatiquement
- B) Anchor/Foreign pattern, client garde IP original via tunnel
- C) Roaming impossible (VLAN mismatch)
- D) Route statique configurée

**Réponse**: B) Anchor/Foreign pattern, client garde IP original via tunnel ✓

---

**Question 25**: Anchor Controller dans intercontroller roaming est :
- A) WLC avec meilleur signal
- B) Original WLC où client initialement associé
- C) WLC avec plus APs
- D) geografiquement plus proche

**Réponse**: B) Original WLC où client initialement associé ✓

---

**Question 26**: Foreign Controller dans roaming pattern est :
- A) WLC dans pays différent

**Question 27**: Mobility Group configuration purpose :

**Question 28**: Roaming MÊME Mobility Group vs DIFFÉRENT groupe :
