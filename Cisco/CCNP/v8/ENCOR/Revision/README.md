# CCNP ENCOR v8 - Enterprise Core
## Révisions Cisco CCNP - Certification 350-401

---

## 📚 Description du cours

**CCNP Enterprise Core (ENCOR) v8** est le cours de base pour la certification CCNP Enterprise. Ce cours couvre les technologies essentielles de l'infrastructure réseau d'entreprise, de la couche 2 à la couche 7, incluant les réseaux sans fil, la virtualisation et l'automatisation.

**⚠️ Important :** Ce cours v8 sera prochainement remplacé par la v9 sur NetAcad. Date limite pour terminer le cours : À vérifier sur votre compte NetAcad.

**Certification visée :** Cisco 350-401 ENCOR  
**Durée estimée :** ~150-200 heures  
**Modules :** 29 modules + 9 checkpoints + 2 examens finaux

---

## 🎯 Objectifs d'apprentissage

Ce cours couvre les domaines suivants :

### 1. Architecture (15%)
- Design hiérarchique réseau d'entreprise
- Technologies Fabric (SD-Access, VXLAN)
- Virtualisation

### 2. Virtualisation (10%)
- Virtualisation des périphériques réseau
- NFV (Network Function Virtualization)

### 3. Infrastructure (30%)
- Couche 2 (STP, VLANs, EtherChannel)
- Couche 3 (Routage statique/dynamique : EIGRP, OSPF, BGP)
- Services réseau (DHCP, DNS, NAT)
- Wireless (architecture, sécurité, mobilité)

### 4. Services réseau (10%)
- DHCP, DNS, NTP
- SNMP, Syslog, NetFlow
- QoS

### 5. Sécurité (20%)
- Contrôle d'accès réseau
- Sécurité des périphériques
- Sécurité sans fil

### 6. Automatisation (15%)
- Programmabilité réseau
- APIs REST
- Outils d'automatisation (Ansible, Python)

## 📂 Structure des révisions

### Notes de cours
Dossier `Notes/` - Notes détaillées par module (1000-1500 lignes)

### Fiches de révision
Dossier `Fiches/` - Fiches synthétiques (200-300 lignes)
- Résumés des concepts clés
- Tableaux de commandes
- Diagrammes et comparaisons

### QCM
Dossier `QCM/` - Questions à choix multiples :
- QCM par module (20-30 questions)
- Format : Questions + Réponses détaillées avec explications

### Checkpoint Exams
Dossier `Checkpoint-Exams/` - Examens par bloc (9 checkpoints)
- Examens intermédiaires couvrant plusieurs modules
- 40-50 questions par checkpoint

### Mock Exams
Dossier `Mock-Exams/` - Examens blancs complets :
- CCNP ENCOR Final Exam (simulation NetAcad)
- CCNP ENCOR 350-401 Practice Exam (simulation certification)
- 100-120 questions, durée 120 minutes

## ⚡ Commandes IOS essentielles (CCNP Level)

### STP Configuration
```cisco
! Définir le root bridge
spanning-tree vlan 10 root primary

! Configurer la priorité manuellement
spanning-tree vlan 10 priority 4096

! PortFast et BPDU Guard
interface Gi0/1
 spanning-tree portfast
 spanning-tree bpduguard enable

! Rapid-PVST+
spanning-tree mode rapid-pvst
```

### EtherChannel Configuration
```cisco
! Configuration LACP
interface range Gi0/1-2
 channel-group 1 mode active
 
! Vérification
show etherchannel summary
show etherchannel port-channel
```

### OSPF Configuration
```cisco
! OSPF basique
router ospf 1
 router-id 1.1.1.1
 network 10.0.0.0 0.0.0.255 area 0
 
! Interface OSPF
interface Gi0/0
 ip ospf 1 area 0
 ip ospf network point-to-point
```

### BGP Configuration
```cisco
! eBGP
router bgp 65001
 neighbor 203.0.113.2 remote-as 65002
 network 10.0.0.0 mask 255.255.255.0
 
! iBGP
router bgp 65001
 neighbor 10.0.0.2 remote-as 65001
 neighbor 10.0.0.2 update-source Loopback0
```

## 🎯 Différences CCNA → CCNP

### Niveau CCNA
- Configuration de base
- Concepts fondamentaux
- Petits réseaux (< 200 appareils)
- Dépannage simple

### Niveau CCNP (ENCOR)
- Configuration avancée et optimisation
- Design et architecture d'entreprise
- Grands réseaux (> 1000 appareils)
- Dépannage complexe et méthodique
- Redondance et haute disponibilité
- Automatisation et programmabilité
- Intégration multi-technologies
